# CFTR Mutation Classes — Interactive Visualization

An interactive educational tool for exploring the six classes of CFTR gene mutations associated with Cystic Fibrosis.

## 🔬 Features

- Visual cellular pathway showing where each mutation class disrupts CFTR protein production
- Animated indicators for Nucleus, ER & Golgi, and Plasma Membrane stages
- Detailed mechanism, functional impact, and representative variants for each class
- Fully responsive design (mobile & desktop)

## 🚀 Live Site

| File | Purpose |

## 🛠 How to Deploy

1. Create a new GitHub repository
2. Upload `index.html` and `_config.yml` to the root of the repo
3. Go to **Settings → Pages**
4. Under **Source**, select `Deploy from a branch`
5. Choose **main** branch and **/ (root)** folder
6. Click **Save** — your site will be live in ~1 minute
